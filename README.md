## Unity Recruitment Task – Physics-Based D12 Dice

A recruitment assignment focused on implementing a realistic physics-based 12-sided dice simulation in Unity.

### Key Features

* Implemented a fully physics-driven D12 dice with accurate result detection based on its final resting face.
* Developed a drag-and-throw interaction that preserves mouse velocity to simulate natural dice throws.
* Implemented automatic throw validation, preventing invalid rolls caused by insufficient force.
* Designed an inspector-friendly configuration allowing face values to be easily customized.
* Built a UI displaying the current result, cumulative score and supporting automatic dice rolls.
* Ensured robust gameplay by preventing the dice from leaving the play area and guaranteeing that every throw produces a valid result.
